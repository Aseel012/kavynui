# Sponsoring kavynUI

kavynUI is a free, MIT-licensed library of animated React components and page sections. It stays free. Sponsors cover the time it takes to keep it maintained, tested and growing.

## Why sponsor

- **Your brand in front of people building product UIs.** kavynUI is built for developers putting together landing pages, dashboards and app screens: the people who choose hosting, auth, forms, email and analytics tools.
- **A library built to last.** 101 components and sections, installed as source through the shadcn CLI, with CI that installs every component into fresh TypeScript and JavaScript apps on every pull request.
- **Found by coding agents, not only people.** The registry is searchable through shadcn's MCP server, and the site publishes `llms.txt` for tools like Claude Code and Cursor.
- **A clean, honest placement.** Sponsor tiles are monochrome and sit with the rest of the design. No pop-ups, and no remote scripts or images: the logo is served from the site itself. Sponsor links are marked `rel="sponsored"`.

kavynUI is a young project. Sponsorship is offered month to month, so you can start small and see whether it works for you.

## Tiers

The home page sponsor wall has **six spots**. Spots are filled in the order sponsors join.

| Tier | Placement |
| --- | --- |
| **Lead sponsor** (one spot) | First tile on the kavynui.com home page sponsor wall, logo at the top of the README Sponsors section and of this file, and a thank-you in the release notes for each month you sponsor |
| **Sponsor** | Logo tile on the kavynui.com home page sponsor wall, logo in the README Sponsors section and in this file |
| **Backer** | Name and link in the README Sponsors section and in this file |

Pricing is monthly, with a one-month minimum. Email for current rates and availability.

### Logo requirements

- A **single-colour SVG**. The wall draws every logo in the theme's text colour so it looks right in dark and light mode.
- A link to an `https://` page of your choice.
- The logo is hosted in the repo (`public/sponsors/`), never loaded from a remote server, because the site's content security policy only allows same-origin images.

## How to sponsor

**Companies:** email **shaikhmdaseel@gmail.com** with the subject "Sponsoring kavynUI" and include your company name, website and the tier you're interested in. The empty "Your logo here" tiles on [kavynui.com](https://kavynui.com) open the same email, pre-filled.

**Individuals:** the most direct way to support the project is to buy a template at [kavynui.com/templates](https://kavynui.com/templates). Starring the [repo](https://github.com/Aseel012/kavynui) also helps other people find it.
